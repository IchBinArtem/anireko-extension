# AniReko для Chrome

Расширение распознаёт аниме и серию на страницах с HTML5-плеером и помогает не терять прогресс просмотра.

[Установить из Chrome Web Store](https://chromewebstore.google.com/detail/leojnckhalnjpfcpiabhdcgnnlfppdap)

## Возможности

- распознаёт аниме и номер серии;
- показывает совместимость тайтла с вашим вкусом в AniReko;
- сохраняет прогресс просмотра в браузере;
- по желанию синхронизирует статус и прогресс с аккаунтом AniReko.

Интерфейс автоматически работает на русском или английском языке — в зависимости от языка Chrome.

## Как пользоваться

1. Установите расширение из Chrome Web Store.
2. Откройте страницу с аниме в HTML5-плеере и запустите воспроизведение.
3. Нажмите значок AniReko на панели Chrome.

Если Chrome ограничил расширению доступ к странице, разрешите его через меню **Доступ к сайтам**.

## Установка из исходников

1. Скачайте репозиторий и распакуйте архив.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`.
