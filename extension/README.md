# AniReko для Chrome

Расширение помогает не терять прогресс при просмотре аниме на разных сайтах.

## Что умеет

- распознаёт аниме, серию и озвучку;
- если совпадение неоднозначно, выделяет иконку оранжевым `!`, предлагает выбрать или найти тайтл в AniReko вручную; любой подтверждённый выбор можно изменить, а привязка хранится только в этом браузере;
- понимает эквивалентные русские числительные в названиях (`три тысячи = 3 тысячи = 3000`) и не предлагает кандидатов с явно другим числом;
- если название с явным сезоном не найдено, ищет базовое название и подтверждает нужный сезон через точный псевдоним каталога; без однозначного подтверждения предлагает ручной выбор;
- показывает прогресс просмотра;
- показывает локальную активность за 12 недель в виде тепловой карты: квадратики отражают записанное время, штриховка означает отсутствие записи, а не доказанный нулевой просмотр; количество серий — серии с активностью, не обязательно досмотренные;
- по желанию синхронизирует прогресс с аккаунтом AniReko; ручная синхронизация использует сохранённую локальную позицию текущего тайтла, даже если после перезагрузки страницы плеер ещё ждёт нажатия «Продолжить просмотр»; для старой истории без каталожного ID один раз просит подтвердить конкретное аниме;
- показывает процент совпадения с вашим вкусом.

Интерфейс автоматически работает на русском или английском языке — по языку Chrome.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `extension`.

Для автоматического распознавания на сайтах разрешите расширению доступ через штатное меню Chrome **Доступ к сайтам**.

## Обновление

Скачайте свежую версию, замените файлы и нажмите **Обновить** на странице `chrome://extensions`.

Если в старой вкладке появляется «Нет подключения к странице», проверьте доступ к сайту в меню Chrome. Кнопка в popup позволяет перезагрузить страницу с предупреждением о прерывании воспроизведения. Если это не помогает, откройте страницу в новой вкладке. Автоматической перезагрузки нет; отсутствие связи не считается ошибкой распознавания аниме.

## Данные и безопасность

Расширение работает с AniReko по HTTPS и никогда не подключается к базе данных напрямую. Серверная реализация API, PHP-код, SQL, схема и хранилище данных остаются закрытыми.
