# AniReko для Chrome

Расширение помогает не терять прогресс при просмотре аниме на разных сайтах.

## Что умеет

- распознаёт аниме, серию и озвучку;
- показывает прогресс просмотра;
- по желанию синхронизирует прогресс с аккаунтом AniReko;
- показывает процент совпадения с вашим вкусом.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `extension`.

Для автоматического распознавания на сайтах разрешите расширению доступ через штатное меню Chrome **Доступ к сайтам**.

## Обновление

Скачайте свежую версию, замените файлы и нажмите **Обновить** на странице `chrome://extensions`.

## Данные и безопасность

Расширение работает с AniReko по HTTPS и никогда не подключается к базе данных напрямую. Серверная реализация API, PHP-код, SQL, схема и хранилище данных остаются закрытыми.
