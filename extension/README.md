# AniReko — трекер просмотра аниме

Chrome MV3-расширение с универсальным provider-independent детектором во всех разрешённых Chrome HTTP(S)-фреймах. `<all_urls>` нужен основной функции, а не «про запас»: только так расширение автоматически видит произвольный cross-origin плеер. Где запускать AniReko — при нажатии, на выбранных сайтах или на всех — пользователь выбирает штатно в меню/настройках Chrome; popup не дублирует этот менеджер.

- ищет anime/media-кандидата по метаданным страницы (h1 / og:title / title);
- маппит распознанный тайтл на `anime_id` каталога через публичный `GET /api/search` (наружу уходит ТОЛЬКО очищенная строка тайтла, без URL и идентификаторов);
- читает выбранную серию каскадом: live `episodeChange`/валидированные iframe-сообщения → активные атрибуты и `select`/selected-контролы → строгий query-параметр `episode|episode_number|ep|seria` URL документа с реальным `<video>`; URL-fallback принимает только однозначное целое `1..5000` и не смотрит query верхней страницы;
- читает выбранную озвучку из активных translator/translation-контролов и явно подписанного значения combobox (`Озвучка`/`Перевод`/`Voice`/`Dub`), удаляя служебный счётчик эпизодов и отбрасывая числовые/boolean значения;
- привязывает серию и озвучку к конкретному документу плеера: сигнал дочернего iframe не меняет соседний плеер, а сигнал верхней страницы применяется только к единственному видимому активному плееру; если proprietary iframe создаёт `<video>` лишь после клика, серия заранее читается из его строгого URL-параметра; скрытая реклама и неоднозначные iframe fail-closed;
- ищет `<video>` непосредственно во всех доступных фреймах, включая cross-origin embed'ы, и в shadow DOM — открытых и закрытых root'ах (`chrome.dom.openOrClosedShadowRoot`); web-component плееры детектятся по custom-тегам;
- серия опциональна: фильмы и неразмеченные плееры трекаются без номера серии (история пишется при длительности ≥5 мин — реклама не попадает);
- если пользователь отдельно согласился на диагностику и плеер прочитать не удалось, после 15с грейса отправляет hostname + структурную пробу без cookies/path/query (дедуп 1 раз на хост в 7 дней);
- если аниме не распознано, попап скрывает плеер, статистику, детали и аккаунт-синхронизацию; вместо них показывает только понятное пустое состояние и кнопку «Здесь есть аниме». По явному клику уходит hostname + та же структурная проба без URL/path/query, title/контента страницы, cookies, аккаунта и истории (дедуп 1 раз на хост в 7 дней); проверка аккаунта на такой странице не выполняется;
- показывает статус (`смотрю ×N` / `пауза` / `просмотрено` при ≥80%) и прогресс, учитывает `playbackRate`;
- хранит минимальную локальную историю: тайтл, серия, озвучка, позиция, длительность, просмотренные секунды и факт прохождения 80%; seek-сегменты и поведенческий профиль скорости не собираются;
- ведёт отдельное состояние нескольких плееров и выбирает активный по реальному playback — скрытые/остановленные плееры (реклама) не получают приоритет над играющим видимым;
- переживает SPA-навигацию (pushState/popstate) — тайтл и эпизод переоцениваются при смене URL без перезагрузки;
- показывает состояние аккаунта: cookie-сессия сайта общая с расширением (host permission), но синхронизация дополнительно и явно привязывается к неизменяемому `user_id`; смена аккаунта на сайте приостанавливает запись до подтверждённой перепривязки (защита от случайной записи в demo/support account);
- кэш персонального match% также разделён по `user_id`; bulk-чтение прогресса передаёт ожидаемый `user_id`, а сервер сверяет его с cookie-сессией до чтения данных;
- **автоотметка «смотрю»** (fail-closed: до явного включения и привязки к текущему аккаунту синк выключен): ставит `watching` после двух просмотренных серий (≥80% каждая) **либо сразу после полностью просмотренной серии №2+** — это покрывает позднюю установку расширения, когда предыдущих серий нет в локальной истории; одна только серия №1 остаётся сигналом «попробовал». Для фильма без номера серии достаточно одного полного просмотра. Запись идёт через `/api/anime/status.php` только при точном матче каталога, никогда не перетирает существующий `watching`/`completed`/`dropped`; наружу уходит только `anime_id` + ожидаемый `user_id` для проверки привязки (целевой пользователь всё равно определяется сервером только из cookie);
- **resume-прогресс в «Моём списке»** (тот же sync-тогл): на pause/ended/смене серии/закрытии вкладки (и не чаще 1 раза/5 мин при плейбэке) шлёт `anime_id + серия + позиция + озвучка` на `/api/extension/progress.php` — watching-карточки в `/lists` показывают «▶ Серия 7 · остановился на 12:34 · AniLibria · вчера»; URL/домен источника не отправляется;
- progress POST выполняются последовательно, поэтому более старый ответ не может перезаписать новую позицию; при закрытии вкладки после перезапуска service worker финальная точка восстанавливается из `chrome.storage.session`;
- **«Остановился» в попапе**: открыл распознанное аниме на любом сайте → попап показывает «Серия 8 · 12:34 · AniDUB · вчера». Источник — resume-bulk кэш: весь прогресс юзера одной картой (`GET ?all=1`, не чаще 1 раза / 30 мин) + обновляется своими же POST-ами; фоллбэк — локальная история браузера (гость/оффлайн). Пока видео играет — строка скрыта и сеть не дёргается. Кнопка «⟳ синхронизировать» в попапе форсит bulk-GET (кейс «только что смотрел с телефона») с кулдауном 60с, переживающим переоткрытие попапа;
- **match% на иконке и в попапе** (вместо floating-виджета поверх плеера): бейдж `NN` цветом вердикта (палитра сайта `--match-*`), в попапе процент и короткий вердикт встроены в карточку распознанного аниме; гость видит подсказку войти, low-confidence/suppressed % не показывается. Шапка использует фирменный знак `A` из favicon AniReko, у карточки одна главная CTA «Открыть в AniReko», а плеер, прогресс и локальная статистика вынесены во вторичный компактный слой без постера;
- бережёт сервер: title→anime_id кэшируется глобально (LRU 200, TTL 7 дней), одновременные запросы дедупятся, при ошибках API — экспоненциальный backoff до 30 мин; авто-отметка дедупится per серия + debounce 120с;
- хранит долговременные настройки/историю в закрытом для content scripts `chrome.storage.local`, а URL-bearing состояние вкладки — только в `chrome.storage.session`; кнопка удаления очищает локальную историю, кэши, настройки и account binding.

## Граница открытого репозитория

Публичный репозиторий содержит только клиентские исходники расширения, тесты, документацию и инструменты воспроизводимой сборки. HTTP-граница с AniReko описана в `extension/api-contract.json` и проверяется клиентскими и браузерными тестами.

Расширение обращается к AniReko только по HTTPS и никогда не подключается к базе данных напрямую. Серверная реализация API, PHP-код, SQL, схема и хранилище данных, конфигурация, инфраструктура деплоя и секреты остаются в закрытом репозитории.

## Установка в Chrome

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку `extension`.
5. Закрепите `AniReko Recognition Spike` на панели.

После изменения manifest, service worker или content scripts нажмите Reload на странице расширений и обновите вкладку с видео.

## Проверка

1. Нажмите AniReko и подтвердите first-run disclosure. Нужный охват задаётся штатным пунктом Chrome «Доступ к сайтам»; для автоматического распознавания произвольных встроенных плееров выберите «На всех сайтах».
2. Запустите видео: на иконке появится бейдж ▶ (пауза — ⏸), в попапе — карточка тайтла с кнопкой «Открыть в AniReko», эпизодом и озвучкой; ниже компактно показаны статус плеера, прогресс и локальная статистика.
3. Перемотайте за 80%: бейдж на иконке сменится на ✓, статус — на «просмотрено».

Store-сборка всегда использует `https://anireko.com`. E2E копирует расширение во временную папку и заменяет build-time runtime config; пользовательское storage не может перенаправить API.

## Локальные тесты

Unit (из корня репозитория; путь к файлу явный — glob в PowerShell не разворачивается):

```bash
node --test extension/tests/*.test.js
```

E2E (реальный Chromium с загруженным расширением + hermetic fixture-сервер):

```bash
cd tests/e2e && npm run test:extension
```
